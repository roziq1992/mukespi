# mukespi

## Tanda tangan visual surat

Surat yang diteruskan ke Direktur harus berupa PDF agar dapat dipratinjau dan
ditandatangani di sistem. Direktur membubuhkan tanda tangan langsung pada
halaman PDF dan dapat menyeretnya untuk mengatur posisi sebelum menyimpan.
Fitur ini menghasilkan tanda tangan visual, bukan tanda tangan elektronik
tersertifikasi VIDA TTE. Setelah mengambil kode aplikasi, jalankan
`composer install --no-dev` dan pastikan ekstensi PHP `gd` serta `zlib` aktif.
Dependensi PDF mendukung PHP 7.0 yang digunakan XAMPP 7.
